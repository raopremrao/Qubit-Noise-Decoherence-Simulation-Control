# Qubit Noise Decoherence Simulation & Control

## Overview

Simulate how noise affects the qubit and then design a **control pulse** or **Error mitigation method** to reduce error.

## This will implement:

* Amplitude damping 
* Phase damping 
* Depolarizing noise 
* T1 relaxation 
* T2 dephasing
* Bloch sphere visualization 
* Fidelity vs noise plot 
* Simple control pulse to reduce error
* Interactive Streamlit Simulator

## Tools: 

* Python
* QuTip
* Qiskit
* NumPy
* Matplotlib
* Streamlit

## Features:
- Open quantum system simulation
- Noise modeling
- Decoherence simulation
- Fidelity analysis
- Bloch sphere visualization
- Interactive dashboard
