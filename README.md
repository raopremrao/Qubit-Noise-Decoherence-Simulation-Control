# Qubit-Noise-Decoherence-Simulation-Control

## Project Idea

Simulate how noise affects the qubit and then design a **control pulse** or **Error mitigation method** to reduce error.

## This will implement:

* Amplitude damping 
* Phase damping 
* Depolarizing noise 
* Bloch sphere visualization 
* Fidelity vs noise plot 
* Simple control pulse to reduce error

## Tools: 

* Python
* Qiskit
* NumPy
* Matplotlib
