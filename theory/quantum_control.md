# Quantum Control

Quantum control is used to manipulate qubit states using control pulses.

Hamiltonian:
$$H(t) = H_0 + u(t)H_c$$

Where:
$u(t)$ is control pulse.

Control pulses can:
- Implement quantum gates
- Reduce decoherence
- Improve fidelity
- Perform error mitigation

This project simulates control pulses and fidelity improvement.
